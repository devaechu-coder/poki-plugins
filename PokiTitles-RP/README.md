## 문의함 GUI (PokiHelp)

`/문의함` 상자 화면을 꾸미는 그림. PokiHelp 가 상자 제목에 아래 글자를 넣으면 배경·헤더가 그려진다.

- 배경(192×232)·헤더(192×60) 원본은 768×928 / 768×240 이라 256px 제한 때문에 256px 조각으로 잘라 넣음
  (`assets/pokihelp/textures/font/`, 몸통 3×4 조각, 헤더 3조각)
- 글자: `\ue810`~`\ue81b` 미처리 몸통, `\ue820`~`\ue82b` 완료 몸통, `\ue830`~`\ue832` / `\ue840`~`\ue842` 헤더
- 칸 이동 공백: `\ue800` -1, `\ue801` -192, `\ue802` -16, `\ue803` +16
- 아이콘: 종이(PAPER) + CustomModelData 8301~8313 (`assets/minecraft/models/item/paper.json`)

| 번호 | 아이콘 | 번호 | 아이콘 |
| --- | --- | --- | --- |
| 8301 | 버그 | 8308 | 미처리 |
| 8302 | 신고 | 8309 | 처리 완료 |
| 8303 | 질문 | 8310 | 닫기 |
| 8304 | 기타 | 8311 | 페이지 |

| 8306 | 다음 | 8313 | 빈 칸 |

다른 리소스팩이 `paper.json` 을 덮어쓰면 아이콘이 그냥 종이로 보임 → 이 팩을 위로 올리기.

## 포키 UI (상점·경매장·스코어보드)

다른 플러그인(CommandMenu 상점·야생, JSTradeShop 코인, Irisauction 유저상점, SimpleScore) 의 config 제목에 그림 글자를 넣어서 꾸미는 것.
`default.json` 맨 앞의 `{"type":"reference","id":"pokiui:ui"}` 가 `assets/pokiui/font/ui.json` 을 불러온다.

- 원본(GPT 제작)은 768px 짜리 한 장 글자였는데 256px 제한 때문에 조각으로 잘라 `\ueb00`~ 에 넣음
- 원래 글자 `\uea10`~`\uea52` 하나 = 조각 여러 개를 이어 붙인 문자열 (폭은 원래와 똑같음). 서버 config 제목도 그 문자열로 바꿔서 써야 함
- 공백: `\uea00` -16, `\uea01` -177, `\uea02` -193, `\uea03` -1 (조각 잇기), `\uea04` -192 (다음 줄)
- `assets/minecraft/textures/gui/container/generic_54.png` — 6줄 상자 기본 그림을 바꿈 (SimpleShopJS 일반 상점용). **모든 6줄 상자에 적용됨**. 싫으면 이 파일만 지우기

## 배포

main 에 올리면 GitHub Actions 가 zip 으로 묶고, `VERSION` 이 새로우면 Releases 에 올린다.
릴리스 설명에 `server.properties` 에 넣을 `resource-pack` 주소와 `resource-pack-sha1` 이 적혀 있다.
(또는 런처가 `resourcepacks` 폴더에 넣어 배포)

## 주의

- 마크 글꼴 텍스처는 한 장이 256px 이하여야 함 (넘으면 안 보임). 지금 배지는 가로 최대 249px.
- 배지 크기는 `default.json` 의 `height` (글자 높이, 보통 글씨는 8). 게임 안에서 더 크게/작게는 PokiName config 의 `title.scale`.
