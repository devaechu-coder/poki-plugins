# PokiLive

콘서트장(POKI LIVE) 공연 연출 플러그인. 서버에만 넣으면 됨 (모드·리소스팩 필요 없음).

## 처음 한 번 설정
1. 무대 **가운데**에 서서 **객석 쪽**을 보고 `/공연 무대`
2. 스크린 **가운데 블록**을 바라보고 `/공연 스크린` → 스크린에 POKI LIVE 가 뜸
   - 글자가 거꾸로(뒷면) 보이면 `/공연 스크린 돌리기`

## 쓰는 법
`/공연 리모컨` — 버튼 상자 GUI. 대부분 이걸로 충분

| 명령어 | 설명 |
| --- | --- |
| `/공연 시작 [제목]` | 3·2·1 카운트다운 → 제목 → 연속 불꽃 → 반짝이 조명 |
| `/공연 끝` | 피날레 불꽃 + "감사합니다!" + 하트 조명 (20초 뒤 조명 꺼짐) |
| `/공연 불꽃 [기본\|별\|하트\|연속\|피날레]` | 무대 쪽 불꽃. 공연 불꽃은 맞아도 안 아픔 |
| `/공연 문구 <내용\|끄기>` | 스크린 글자. 줄바꿈 `\n`, 색 코드 `&d` 등. 색 코드 없으면 분홍·하늘·보라로 바뀜 |
| `/공연 조명 <반짝이\|하트\|음표\|벚꽃\|별빛\|끄기>` | 객석 위로 계속 파티클 |
| `/공연 스포트 [닉\|끄기]` | 반투명 빛기둥이 그 사람을 부드럽게 따라다님 + 주변 실제로 밝아짐 (진하기는 config `spotlight`). 다시 치면 끔 |
| `/공연 멈춤` | 조명·스포트·예약된 불꽃 모두 멈춤 |
| `/공연 티비` | 영상 프레임(TV) 블록을 보고 치면 그 자리 저장 |
| `/공연 치지직 [채널ID\|링크\|끄기]` | 치지직 라이브 주소(토큰 포함)를 받아와서 TV에 연결. 끄기는 일시정지 + TV 투명 |
| `/공연 리로드` | config.yml 다시 읽기 |

권한: `pokilive.admin` (기본 OP)

## 치지직 라이브 TV
- 서버·클라 모두 WATERFrAMES(+WATERMeDIA 2.1.x, CreativeCore, WATERViSION) 필요
- 방송 주소는 토큰이 붙어서 약 17시간 유효 → 공연마다 `/공연 치지직` 다시 치기
- config `chzzk.channel` 에 채널ID 넣으면 리모컨 "치지직 라이브 켜기" 버튼으로 바로 연결
- 성인 방송은 주소를 못 받아옴
- TV 켜져 있는 동안 스크린 문구는 숨김 (영상 가림 방지). `/공연 치지직 끄기` 하면 마지막 문구가 다시 나옴

## 참고
- 제목·카운트다운·효과음은 무대에서 `radius`(기본 64칸) 안에 있는 사람만 받음
- 불꽃 위치는 config 의 `firework-points` (무대 중심 기준 [오른쪽, 앞, 위]). 기본값은 POKI LIVE 스키매틱에 맞춤
- 스크린 글자는 재시작하면 사라짐 → `/공연 문구` 로 다시 띄우면 됨
