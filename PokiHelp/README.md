# PokiHelp

포키 서버 문의 접수 플러그인. 채팅에 "도움!" 치면 도전과제 알림에 묻혀서, 운영진한테만 가는 문의함을 따로 만든 것.

## 빌드

```
mvn package
```

또는 GitHub Releases 에서 jar 받기. `plugins` 폴더에 넣고 서버 재시작. (Java 21, Spigot API 1.21.1)

꾸민 문의함 화면은 [PokiTitles-RP](../PokiTitles-RP/) 1.2.0 이상이 있어야 보인다 (운영진만). 팩이 없으면 config 의 `gui.resource-pack: false`.

## 유저 명령어

| 명령어 | 설명 |
| --- | --- |
| `/문의 <내용>` | 운영진한테만 문의 보내기 (종류 기타) |
| `/문의 버그\|신고\|질문\|기타 <내용>` | 종류 골라서 보내기 |
| `/신고 <내용>` | `/문의 신고` 와 같음 |
| `/문의` | 사용법 + 종류 버튼 (누르면 채팅창에 명령어 채워짐) |
| `/문의 목록` | 내가 보낸 문의 최근 5건, 처리됐는지 |

- 보낸 위치(월드·좌표)도 같이 저장
- 쿨타임 `cooldown-seconds`(기본 60초), 처리 안 된 문의 `max-open-per-player`(기본 3건)까지
- 운영진이 처리하면 "운영진이 문의를 확인했어요!" 알림 (꺼져 있었으면 다음 접속 때)

## 운영진

운영진 = OP 이거나 config `staff-permissions` 의 권한이 있는 사람 (기본 `pokihelp.staff`, `pokiname.admin`).

- 새 문의가 오면: 채팅 박스 + 화면 큰 글씨 + 효과음. 채팅의 `[이동]` `[처리]` `[문의함]` 을 누르면 바로 실행
- 접속하면 미처리 문의가 있을 때 "미처리 문의 N건 [문의함 열기]"

| 명령어 | 설명 |
| --- | --- |
| `/문의함` | 문의함 GUI |
| `/문의함 목록` | 채팅으로 미처리 10건 (콘솔도 됨) |
| `/문의함 이동 <번호>` | 그 사람한테 이동 (접속 안 했으면 보낸 곳) |
| `/문의함 처리 <번호>` | 처리 완료 |
| `/문의함 리로드` | config.yml · tickets.yml 다시 읽기 |

### 문의함 GUI

| 칸 | 내용 |
| --- | --- |
| 0~44 | 문의 (최신순). 좌클릭 이동 / 우클릭 처리 완료 (완료 목록에선 미처리로 되돌리기) / Shift+좌클릭 삭제 |
| 45 / 53 | 이전 / 다음 페이지 |
| 47 | 종류 필터 (전체 → 버그 → 신고 → 질문 → 기타) |
| 48 / 50 | 미처리 목록 / 처리 완료 목록 |
| 49 | 페이지, 건수 |
| 51 | 닫기 |

리소스팩 모드는 상자 제목에 PokiTitles-RP 의 그림 글자를 넣어서 배경·헤더를 그리고, 아이콘은 종이 + CustomModelData 8301~8313.
장식 헤더가 상자 위로 44px 튀어나와서 GUI 배율이 크면 위가 잘릴 수 있음 → 배율 한 단계 낮추기.

## 파일

- `plugins/PokiHelp/config.yml` — 설정
- `plugins/PokiHelp/tickets.yml` — 문의 기록. 처리 완료는 `keep-done-days`(기본 30일) 뒤 자동 삭제
