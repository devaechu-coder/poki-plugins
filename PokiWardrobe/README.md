# PokiWardrobe

포키 서버 치장 플러그인. 옷장 GUI(`/치장`), 모자 치장, 파티클 치장.
PokiName 처럼 **패킷을 건드리지 않고 Bukkit 기본 API만** 쓴다 (아크라이트 호환).

## 명령어

| 명령어 | 설명 |
| --- | --- |
| `/치장` | 옷장 열기 (모자 / 파티클 탭, 가진 건 눌러서 착용·해제, 없는 건 회색 잠금 + 얻는 방법) |
| `/치장 파티클` | 파티클 탭으로 바로 열기 |
| `/치장 파티클숨기기` | 다른 사람 파티클 숨기기/다시 보기 (옷장 위쪽 버튼도 같음) |
| `/치장 벗기` | 치장 전부 벗기 |
| `/치장관리 지급 <마크닉> <치장\|전체>` | 치장 주기 (접속 안 해도 됨) |
| `/치장관리 회수 <마크닉> <치장\|전체>` | 치장 뺏기 (착용 중이면 벗김) |
| `/치장관리 보기 <마크닉>` | 가진 치장 보기 |
| `/치장관리 목록` | 치장 목록 |
| `/치장관리 리로드` | config.yml · cosmetics.yml 다시 불러오기 |

영어로는 `/wardrobe`, `/wardrobeadmin`. 치장 이름은 한글로 (`꽃_모자`, 띄어 써도 됨).

권한
- `poki.wardrobe.use` (기본 OP): config 의 `open-to-everyone: false` 일 때 `/치장` 쓰려면 필요. **유저 테스트 동안은 false 로 운영진만**, 정식 오픈 때 true
- `poki.wardrobe.admin` (기본 OP): `/치장관리`

## 모자

모자 아이템을 머리 칸에 씌운다. 리소스팩 모델은 `custom_model_data` (cosmetics.yml 의 `model`, **1101~1199**).
모델이 나오기 전엔 바닐라 아이템(`material`)으로 임시 테스트, 모델이 생기면 `material`·`model` 만 바꾸고 리로드.

아이템 유실 방지
- 쓰고 있던 투구는 **인벤토리로 옮김**. 자리가 없으면 착용을 거부 (아무것도 버리지 않음)
- 모자 아이템은 표시(PDC)가 붙어서 집기·옮기기·숫자키·버리기 막힘, 죽어도 안 떨어지고 부활하면 다시 씌움
- 모자 쓴 채로 투구 우클릭(바꿔 끼기) 막음 → "모자 먼저 벗기" 안내
- 2초마다 점검: 머리 칸이 아닌 곳(인벤토리·손·상자)의 모자 아이템은 지움 (복사 방지), 벗겨진 모자는 다시 씌움
- 나갈 때·플러그인 꺼질 때 벗기고 들어올 때 다시 씌움 → 플러그인을 빼도 모자 아이템이 안 남음
- 투구 아이템을 임시 모자로 써도 방어력 0

## 파티클

`particles.interval-ticks`(기본 5틱)마다 발밑에 파티클. `moving-only: true` 면 움직일 때만.
보는 사람마다 따로 보내서 "파티클 숨기기" 한 사람한테는 안 보냄. `view-distance` 칸 밖은 안 보냄.
투명화(물약 포함)·관전자·사망·vanish 중이면 안 나옴.
쓸 수 있는 파티클: 데이터 없는 바닐라 파티클 + `DUST`(색 지정) + `NOTE`.

## 다른 플러그인에서 해금하기 (2차: 코블달러 구매, 후원 보상, 이벤트)

```java
PokiWardrobe api = PokiWardrobe.api();
api.unlock(uuid, "꽃_모자");   // 새로 얻었으면 true, 접속 중이면 알림
api.lock(uuid, "꽃_모자");
api.has(uuid, "꽃_모자");
```
콘솔 명령어로도 됨: `치장관리 지급 {player} 꽃_모자`

## 파일

- `plugins/PokiWardrobe/config.yml` — 공개 여부, 파티클 빈도
- `plugins/PokiWardrobe/cosmetics.yml` — 치장 목록 (모자·파티클)
- `plugins/PokiWardrobe/wardrobe-players.yml` — 플레이어별 가진 치장 / 착용 / 파티클 숨기기
