# PokiPasture

목장 블록(코블몬 `cobblemon:pasture`) 설치 제한.

- **본인이 주민인 마을(Towny) 땅에만** 설치할 수 있어요. 야생·남의 마을은 막혀요.
- **마을 하나에 2개까지** (`config.yml` 의 `limit`).
- 부서진 목장 블록은 다음에 셀 때 자동으로 빠져요 (부수기·폭발 따로 안 잡아도 됨).
- 운영진(`poki.pasture.bypass`, 기본 OP)은 제한 없이 설치.
- 이 플러그인을 넣기 **전에** 설치된 목장 블록은 기록이 없어서 세지 않아요.

## 명령어
| 명령어 | 하는 일 |
| --- | --- |
| `/목장블록` | 우리 마을 목장 블록 개수와 위치 |
| `/목장블록 reload` | 설정 다시 읽기 (운영진) |

## 필요한 것
- Towny (없으면 운영진 말고는 목장 블록 설치가 전부 막힘)
