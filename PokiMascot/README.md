# PokiMascot

포키냥 마스코트를 스폰 등에 세우는 플러그인. 모드 없이 **리소스팩 3D 모델 + 서버 플러그인**만으로 동작.

- 모델: 리소스팩 [PokiTitles-RP](../PokiTitles-RP/) 1.4.0 이상 (`paper` + custom_model_data `8401` → `poki:item/pokinyang`)
- 세우는 방식: 아이템 디스플레이(모델) + 상호작용 엔티티(클릭 판정) 한 쌍. 월드에 저장돼서 재시작해도 그대로
- 우클릭하면 config 의 안내 메시지를 한 묶음씩 차례로 보여줌 + 효과음
- 위아래로 천천히 둥실둥실 (끌 수 있음)

## 명령어 (OP / `pokimascot.admin`)

| 명령어 | 설명 |
| --- | --- |
| `/포키냥 소환 [크기]` | 서 있는 블록에, 보고 있는 방향(45도 단위)으로 세움. 크기 1 ≈ 2블록 높이, 기본 1.5 |
| `/포키냥 돌리기 [각도]` | 가장 가까운 포키냥을 돌림 (기본 45도). 방향이 반대면 `180` |
| `/포키냥 제거` | 가장 가까운 포키냥(6칸 안) 지우기 |
| `/포키냥 리로드` | config.yml 다시 읽기 |
