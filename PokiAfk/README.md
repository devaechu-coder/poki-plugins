# PokiAfk

오래 잠수하면 킥. 기본 **1시간**, 킥 1분 전에 화면 경고. 운영진(`pokiafk.exempt`, 기본 OP)은 제외.

활동으로 치는 것: 시점 돌리기, 땅 위에서 걷기(물속·탈것·겉날개는 빼서 물길·잠수풀로 못 버팀), 채팅, 명령어, 블록 부수기·놓기, 우클릭, 인벤토리.

## 명령어 (OP)

| 명령어 | 설명 |
| --- | --- |
| `/잠수` | 설정과 잠수 오래된 사람 10명 |
| `/잠수 시간 <분>` | 킥까지 시간 (5~1440, 바로 적용) |
| `/잠수 꽉참만 켜기 [빈자리]` / `끄기` | 켜면 서버가 거의 꽉 찼을 때만 잠수 제일 긴 사람부터 킥 (기본 꺼짐) |
| `/잠수 리로드` | config.yml 다시 읽기 |
