# PokiMail

포키 우편함. 운영진 보상을 **접속 안 해도** 우편함에 넣어두고, 유저가 `/우편함` 에서 받는다.
인벤토리가 꽉 차서 못 받은 아이템도 바닥 대신 우편함으로.

- 아이템은 give 명령어 형식(`아이디[컴포넌트]`)으로 저장 → 모드 아이템·치장 그대로
- 저장: `plugins/PokiMail/mail.yml` (바뀔 때만, 비동기)
- 받은·보낸·회수 기록은 서버 로그 `[우편 …]`

## 유저

| 명령어 | 설명 |
| --- | --- |
| `/우편함` | 우편함 창 — 누르면 받기, 아래 상자 = 모두 받기 |
| `/우편함 모두받기` | 창 없이 전부 받기 (인벤에 들어가는 만큼) |

접속할 때 우편이 있으면 채팅으로 알려줌 (누르면 열림).

## 운영진 (`pokimail.admin`, 기본 OP)

| 명령어 | 설명 |
| --- | --- |
| `/우편 지급 <마크닉\|@a> <아이템> [개수] [메모]` | 인벤에 넣고 **남으면 우편함** — `minecraft:give` 대신 (후원 보상·전체 지급) |
| `/우편 보내기 <마크닉\|@a\|전체> <아이템> [개수] [메모]` | 바로 우편함으로. `전체` = 접속 안 한 사람 포함 모두 |
| `/우편 손 <대상> [개수] [메모]` | 손에 든 아이템과 같은 걸 보냄 (내 손은 그대로) |
| `/우편 복사 [대상]` | 손에 든 아이템을 `우편 지급 {player} 아이템 개수` 한 줄로 (눌러서 복사) — ChzzkLink 보상 명령어 칸에 붙여넣기 |
| `/우편 명령 <대상> <보일이름> <명령어>` | 받을 때 콘솔 실행 (`%player%`) — 돈·칭호 등 |
| `/우편 보기 <마크닉>` · `/우편 회수 <마크닉> <번호\|전부>` | 우편함 보기·지우기 |
| `/우편 리로드` | config 다시 읽기 |

## 다른 플러그인

`PokiMail.giveOrMail(Player, ItemStack, from)` · `mail(UUID, ItemStack, memo, from)` · `mailCount(UUID, ItemStack, count, memo, from)` — static, 리플렉션으로 부르기 쉽게.
