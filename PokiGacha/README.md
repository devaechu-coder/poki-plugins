# PokiGacha — 포키 뽑기권

운영진 방송 후원으로 받는 **뽑기권**. 들고 우클릭하면 상자 화면에서 돌아가다 보상 하나가 나옴.

- 보상은 **전부 같은 확률** (보상 개수로 나눔). 꼭 바꾸고 싶으면 `gacha.yml` 의 `weight`
- **치장 중복 금지** (켜 둔 뽑기만): 옷장에 등록했거나 가방에 있는 치장은 안 나옴. 전부 가졌으면 **대체 뽑기권**(기본: 일반도구 1장)
- 뽑기권은 기본 **거래 가능** (config.yml `ticket-tradable: false` 로 바꾸면 거래 불가: 버리기·상자·거래창·액자 X, 죽어도 안 떨어짐)
- 인벤토리가 꽉 차면 뽑기 안 됨 (뽑기권 그대로). 지급할 때 꽉 찼으면 보관 → `/뽑기 받기`
- 접속 안 한 사람에게는 지급 안 함 (config.yml `offline-give: true` 면 다음 접속 때 지급)
- 결과 기록: `plugins/PokiGacha/rolls.csv`

## 명령어

| 명령어 | 누가 | |
|---|---|---|
| `/뽑기` | 모두 | 뽑기 목록 |
| `/뽑기 확률 <종류>` | 모두 | 보상·확률 화면 (이미 가진 치장 표시) |
| `/뽑기 받기` | 모두 | 보관 중인 뽑기권 받기 |
| `/뽑기 편집 <종류>` | 운영진 | 인게임 편집 화면 |
| `/뽑기 만들기 <이름>` · `/뽑기 삭제 <이름> 확인` | 운영진 | 뽑기 종류 추가·삭제 |
| `/뽑기 되돌리기` | 운영진 | 직전 저장 전으로 (여러 번 가능, 백업 30개) |
| `/뽑기 테스트 <종류> [횟수]` | 운영진 | 지급 없이 결과 분포만 |
| `/뽑기 리로드` | 운영진 | gacha.yml 다시 읽기 |
| `/뽑기권 지급 <플레이어\|@a> <종류> [개수]` | 운영진·콘솔 | 후원 연동용 |

권한: `poki.gacha.admin` (기본 OP)

## 편집 화면 (`/뽑기 편집 치장`)

- 인벤토리 아이템 **Shift+클릭**, 또는 아이템 들고 **빈칸 클릭** → 보상으로 추가 (복사본 · 내 아이템은 그대로)
- 보상에 대고 **Q** → 빼기 · 아이템 들고 보상 클릭 → 그 아이템으로 교체
- 아래 줄: 저장 · 취소 · 뽑기권 생김새(들고 클릭) · 이름 바꾸기 · 치장 중복 금지 · 다 가졌을 때 대체 뽑기권 · 테스트 1000번
- 편집하는 동안 그 뽑기는 "점검 중" (유저가 못 뽑음). 저장 안 하고 닫으면 다시 열 때 이어서

## 후원 연동 (PokiDonate 운영진 후원 rewards.yml)

```yaml
- '뽑기권 지급 @a 치장 1'      # 접속자 전원에게
- '뽑기권 지급 @a 일반도구 2'
```
